# Licensed reference inspection (local only)

Inspected 2026-09-22. These packages stay gitignored and are not copied into GoalMates source.

## TaskPilot

Present as a Figma UI kit (`Main File/Main File/Main File.fig`) plus generic Figma documentation HTML. Preview image assets were not extractable in this environment. Usable inspiration only:

- Mobile-first task hierarchy and row density
- Deep-green / high-contrast action emphasis described in the product brief
- Avatar/group presence for shared work
- Bottom-of-phone primary actions

No TaskPilot frames, components, or tokens were copied.

## Dason HTML v1.6.0

Inspected variables, layout, sidebar, and calendar SCSS as composition reference:

- Dense desktop shell (sidebar ~250px, header ~70px, boxed max ~1300px)
- Calendar as a table-like planning surface with uppercase weekday headers
- Forms, menus, and information-dense controls rather than sparse marketing cards
- Neutral gray ink (`#191e22`, `#242a30`) and restrained elevation

Dason’s Bootstrap primary blue (`#1c84ee`), Gulp toolchain, and markup were not reused. GoalMates tokens use a deep-green / paper-cream workbench language instead.
